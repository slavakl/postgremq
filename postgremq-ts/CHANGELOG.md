## [0.2.0-e2e.2](https://github.com/slavakl/postgremq/compare/npm/v0.1.0...npm/v0.2.0-e2e.2) (2026-10-10)


### ⚠ BREAKING CHANGES

* **sql:** postgremq.info() returns schema_version (an integer) instead of db_version; the compatibility errors' version field is renamed accordingly (Go SchemaVersion, TypeScript schemaVersion, Rust schema_version).
* the Go modules moved to postgremq.dev/mq, postgremq.dev/postgremq-go (package postgremq, was postgremq_go) and postgremq.dev/cmd/postgremq; DialFromPool takes a context; the Rust Connection::from_pool is async; every client now checks postgremq.info() when connecting and rejects a database without it (install or upgrade the schema first) or with an unsupported protocol major.

## 0.1.0 (baseline)

The state of the TypeScript client (npm `postgremq`) when independent versioning started. It was never
published as 0.1.0; the first release is the next version above.

- Connection over a node-postgres pool; publish (also on a caller's
  transaction), async-iterator and handler-based consumers.
- Connection-level batched lease renewal and exclusive-queue keep-alive.
- Shared LISTEN session with reconnect and polling fallback.
- Schema migrations (`migrate`, `getMigrationStatus`), compatible with the Go
  client and the CLI.
- Queue-loss teardown (`onClose`, `onQueueFatal` / `'queueFatal'`,
  `QueueFatalError`), graceful shutdown, retry for transient errors.
- Optional OpenTelemetry metrics.

## [0.2.0](https://github.com/slavakl/postgremq/compare/cmd/postgremq/v0.1.0...cmd/postgremq/v0.2.0) (2026-10-10)


### ⚠ BREAKING CHANGES

* The Go modules moved to postgremq.dev/mq, postgremq.dev/postgremq-go (package postgremq) and postgremq.dev/cmd/postgremq, so update import paths. DialFromPool now takes a context, and Rust's Connection::from_pool is async. The CLI --target flag and the Go Migrate options are gone because migrations always go to the bundled version. Clients refuse to connect to a schema without postgremq.info() or with an unsupported protocol major; run the migrations first.
